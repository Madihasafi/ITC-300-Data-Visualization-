# ITC-300-Data-Visualization- Project File

This file includes all the projects and practical activities that will be completed throughout the **Data Visualization (ITC 300)** course. It is provided as a sample format for organizing the work, code, outputs, analysis, and reflections completed during the course.

The projects in this file will cover different stages of working with data, including data loading and preparation, data exploration, data cleaning, statistical analysis, and data visualization. Each project will demonstrate the practical use of Python and relevant libraries to analyze and present data effectively.

This file will be updated throughout the semester as new projects and activities are completed.
